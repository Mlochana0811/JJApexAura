# Salary sheet column buttons

Every template header has Edit header and Remove column buttons. Add column lets HR add a salary allowance in a vacant slot, add a text column, or restore a removed standard field. The supplied Excel format supports six monetary allowance slots and up to 30 custom text columns.

Removing numeric inputs clears their values for all employees after confirmation, changing totals. Restoring starts at zero. Removing identity or calculated result columns affects display only. Renaming headers changes labels, not calculation meaning. Renamed headers are exported. A hidden settings worksheet preserves the column definitions for re-upload. Removed fields are hidden in Excel to preserve template formulas.

Draft sheets support create, view, edit, update and audited deletion with revision checks. Finalized sheets remain immutable. No new migrations or dependencies. Back up your project and database before replacing source; preserve .env, .venv, media and database files.
